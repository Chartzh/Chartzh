## 🚀 Featured Projects

### 🎬 Lumiere — Neural Movie Recommendation System

A neural collaborative filtering recommendation system built using MovieLens 1M.

- Implemented a NeuMF architecture combining Generalized Matrix Factorization (GMF) and a Multi-Layer Perceptron (MLP).
- Trained and evaluated the model on 1,000,209 MovieLens ratings.
- Achieved a test RMSE of **0.8776** on the 1–5 rating scale.
- Exposed model predictions through a FastAPI service deployed on Google Cloud Run.

**Stack:** Python · TensorFlow · FastAPI · Google Cloud Run · Object Storage

### 🧾 Marginku — AI-Powered Receipt & Shelf-Label Processing

An AI application designed to extract information from receipts and shelf labels and calculate product margins.

- Integrated Gemini Vision for image-based text extraction.
- Used fuzzy matching and multilingual sentence embeddings as matching strategies.
- Implemented deterministic margin calculations.
- Built the backend with FastAPI and integrated Supabase.

**Stack:** Python · Gemini API · FastAPI · Supabase · Docker Compose · RapidFuzz

### 🔎 Vye — YouTube Transcript RAG

A retrieval-augmented generation application for answering questions using YouTube transcript content.

- Generated embeddings for semantic retrieval.
- Used PostgreSQL with pgvector for vector search.
- Designed responses around retrieved evidence, including relevant timestamps.

**Stack:** Python · Gemini Embeddings · RAG · PostgreSQL · pgvector

### 🧑‍💻 YAP! — AI Repository Documentation Generator

A developer tool that uses repository context to generate documentation with an LLM.

- Integrated the GitHub API to retrieve repository information.
- Used Gemini API for AI-generated documentation.
- Applied context filtering to focus generation on relevant repository content.

**Stack:** Python · Flask · GitHub API · Gemini API
